# フィールド地図（PWA）

地理院地図・過去の空中写真・植生図・地形分類・旧市町村界・人口メッシュを重ねて見て、
範囲を指定して端末に保存（オフライン利用）できるWebアプリです。iPhone / Android の
「ホーム画面に追加」でアプリとして使えます。

## 公開方法（HTTPSが必須：Service Worker と現在地取得のため）
このフォルダをそのまま静的ホスティングに置くだけです。例：GitHub Pages
1. リポジトリを作り、このフォルダの中身を push
2. Settings → Pages → Branch: main / root
3. 表示されたURLをスマホで開き「ホーム画面に追加」

ローカル確認: `python3 -m http.server 8765` → http://localhost:8765

## 使い方
- 流域：「集水域を求める」→ 地点をタップ。地理院DEM（dem_png）からPriority-Flood＋D8で上流域を計算（広い流域は自動で範囲を広げる）
- 共有：「⤴」ボタンでURLを共有。URLの # 以降に位置・ズーム・表示レイヤが入る
  例: `#map=14/32.43760/131.44010&b=std&o=hillshademap:0.5,relief:0.4&v=pop`
- レイヤ：背景地図・重ねる地図（不透明度スライダ）・旧市町村界（年次）・人口メッシュ・読込GeoJSON
- 範囲保存：「範囲を指定」→ 赤い四角の角をドラッグ → レイヤとズームを選んで「端末に保存」
  - 保存したタイルは圏外でも表示されます（ブラウザのCache Storageに保存）
- データ：
  - 人口メッシュ：令和2年国勢調査 500mメッシュ（e-Stat T001141）を data/pop500/ に同梱（1次メッシュ毎のCSV）。
    他の統計表はe-StatのZIPを読込むことも可
  - 遺跡：文化財総覧WebGISは公開APIがないため「この場所を開く」リンク。県の遺跡GeoJSONは読込可
  - 書き出し：保存範囲をZIP（XYZタイル + GeoJSON）で端末に保存。QGIS等で利用可

## データ出典・条件
- 地理院タイル（国土地理院）
- 地質図：産総研地質調査総合センター 20万分の1日本シームレス地質図V2（CC BY 4.0、z3–13）
- 植生図：環境省生物多様性センター「現存植生図2024」ラスタタイル（G空間情報センター biodic_veg2024tile、z5–15、公共データ利用規約 第1.0版）。
  配信元がCORS非対応のため、画面表示と端末保存（1回1,500枚まで）は可能だが、ZIP書き出しには含められない
- 旧市町村界：歴史的行政区域データセットβ版（CODH）／国土数値情報 行政区域（CC BY-SA 4.0 表記あり）
- 筆ポリゴン：農林水産省「筆ポリゴンデータ（2022年度公開）」。農研機構の都道府県別FlatGeobuf（範囲読み）を利用。ズーム15以上で表示
- 人口：総務省統計局 国勢調査 地域メッシュ統計（e-Stat 統計表 T001141, 500mメッシュ）
